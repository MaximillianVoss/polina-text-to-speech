# Assignment 14 — Text to Speech

Самостоятельный Expo + TypeScript проект: поле `TextInput`, переключатель `SegmentedControl` с English / Finnish / Swedish, кнопка **SAY IT** для чтения текста и **STOP** для остановки.

[Исходное условие](ASSIGNMENT.md) · [Полный разбор и содержимое всех файлов](MANUAL.md)

## Запуск

Требуется Node.js 24. В терминале откройте эту папку:

```sh
npm ci
npm start
```

После установки можно открыть проект в совместимой версии Expo Go. Для браузера: `npm run web`. Для Android-эмулятора: `npm run android`. Для iOS-симулятора на Mac с Xcode: `npm run ios`.

Lock-файл включён в архив. Для самостоятельно созданного проекта без него сначала выполнить `npm install`.

## Проверка

```sh
npm run typecheck
npm test
npm run build
```

`build` экспортирует веб-приложение и JavaScript-пакеты для Android/iOS в `dist`; он не создаёт APK или IPA. Отдельные экспорты: `npm run bundle:android` и `npm run bundle:ios`.

Тесты запускают чистую логику с подставным речевым движком. Они проверяют языки, пустой и слишком длинный ввод, порядок stop → speak, ошибки, быстрые нажатия и завершение работы. Звук и доступность реальных голосов нужно дополнительно проверить на устройстве.

## Как пользоваться

1. Выберите English, Finnish или Swedish.
2. Введите текст на нужном языке. Примеры: `Hello! How are you today?`, `Hei! Mitä sinulle kuuluu?`, `Hej! Hur mår du idag?`.
3. Нажмите **SAY IT**. Новый запуск заменяет предыдущую речь.
4. Нажмите **STOP**, чтобы прервать чтение.

Пустое поле и пробельный ввод дают понятное сообщение. Переключение языка и редактирование текста не запускают озвучивание. Выбор языка меняет произношение, а не переводит текст. Разрешение на микрофон не требуется.

Коды языков: English → `en-US`, Finnish → `fi-FI`, Swedish → `sv-SE`. Приложение ограничивает текст 4000 символами или меньшим лимитом речевого движка.

## Устройство проекта

- `App.tsx` — экран, состояние поля и подписка на управление речью.
- `src/LanguageSelector.tsx` — библиотечный переключатель для трёх языков.
- `src/speech.ts` — проверка текста и контроллер без зависимости от Expo или React Native.
- `src/expoSpeech.ts` — адаптер к `expo-speech`.
- `tests/speech.test.ts` — воспроизводимые тесты контроллера.

Контроллеры одного адаптера используют общую очередь, останавливают старую речь перед новой и используют номер поколения, чтобы игнорировать старые события. При закрытии экрана подписка удаляется, ожидающие запуски отменяются, речь останавливается. Cleanup старого экрана завершается до старта нового после повторного открытия.

## Если звука нет

Проверьте громкость и наличие соответствующих системных голосов. На физическом iPhone `expo-speech` не выдаёт звук при включённом беззвучном режиме. На вебе возможности зависят от браузера и установленных голосов. Эти ограничения описаны в [официальной документации Expo Speech](https://docs.expo.dev/versions/latest/sdk/speech/).

В проекте используется настоящий `@react-native-segmented-control/segmented-control`: нативный переключатель на iOS и реализация библиотеки на Android/web. [Документация Expo SegmentedControl](https://docs.expo.dev/versions/latest/sdk/segmented-control/).
